# domain-glossary

権威用語集は @docs/glossary.md（@import で AGENTS.md からも参照）。本 Skill は要約と利用ガイド。

## 利用ガイド
- 仕様（`docs/specs/`）/ コード（`src/app/domain/`）/ テストの命名は glossary と完全一致させる。
- 新規用語が必要な場合は `docs/glossary.md` に追加してから利用する。
