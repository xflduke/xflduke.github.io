# onprem-review output style

レビュー結果は次の構造で出力する：

## サマリ
- 対象差分の一文要約。
- 仕様適合度（受容基準カバレッジ）。

## Must（merge 不可）
1. **[ファイル:行]** 問題：… / 根拠（仕様番号 or skill 観点）：… / 修正提案：…

## Should（推奨）
- ...

## Nit（任意）
- ...

## セキュリティ / オンプレ
- 外部接続有無、秘密ハードコード、依存許可リスト適合。

トーン：簡潔・断定・根拠付き。冗長な説明や雑談は禁止。
